# Color Match

Point a phone camera at something and see how close its color is to a target color code. A ring in the middle reads the color (like Digital Color Meter), a green marker shows the closest spot in view, and "Set white" corrects for shop lighting.

Open the page on a phone, then install it:
- iPhone: Safari, Share, Add to Home Screen.
- Android: Chrome, menu, Install app.

Plain static files. Everything stays on the phone; nothing is uploaded.
